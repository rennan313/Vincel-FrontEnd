# Tremor Raw (vendorizado)

Os arquivos `.ts`/`.tsx` desta pasta vêm de https://github.com/tremorlabs/tremor
(licença Apache-2.0, incluída em `LICENSE`) — copiados aqui em vez de instalados
via npm porque o projeto é distribuído assim ("Tremor Raw"), não como pacote
publicado. Só os caminhos de import de `BarChart.tsx` foram ajustados pra essa
pasta; o resto do conteúdo é o original deles, inalterado.

Adicionado como teste pontual (ver commit) pra comparar com o `Chart.tsx`
(recharts direto) que o resto do app já usa antes de decidir se vale trocar
mais gráficos.
